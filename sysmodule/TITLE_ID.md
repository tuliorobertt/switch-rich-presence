# Title ID reservado para o projeto

`4200000000075250` é um identificador de projeto no espaço de sysmodules homebrew. Antes de uma distribuição pública, gere/confirme um ID único e mantenha-o igual no NPDM, no caminho `atmosphere/contents/<id>` e no script `package.ps1`.

O ID por si só não torna um executável num sysmodule. O conteúdo `exefs.nsp` deve ser produzido a partir de um alvo sysmodule Atmosphère com NPDM e permissões corretas.
